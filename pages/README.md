# Páginas HTML

As páginas HTML do site ficam nesta pasta e podem ser abertas individualmente:

- `index.html`
- `produtos.html`
- `sobre.html`
- `contato.html`
- `login.html`
- `cadastro.html`
- `perfil.html`
- `carrinho.html`
- `checkout.html`
- `confirmacao.html`

Os arquivos CSS, JavaScript e imagens continuam nas pastas irmãs `css/`, `js/` e `assets/`. Por isso, as páginas usam caminhos `../` para carregar esses recursos.
